Acerca de mí

Empecé por las redes: Cisco Networking Academy me dio las bases de infraestructura y seguridad (CCNA, IT Essentials) antes de que empezara la carrera. Hoy combino esa base con el desarrollo de software — Python, Java y tecnologías web — en proyectos universitarios y trabajo real para clientes a través de Soluciones Dased.

Actualmente trabajo medio tiempo como consultor de ciberseguridad en una entidad del sector público, apoyando administración de amenazas, defensa de red y seguridad de terminales. Me interesa especialmente el punto donde la lógica de programar y la lógica de asegurar un sistema se cruzan: ambas exigen pensamiento estructurado, resolución de problemas y análisis crítico.
